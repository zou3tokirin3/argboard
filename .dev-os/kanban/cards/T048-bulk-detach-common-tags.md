## 目的

T032 で複数選択への一括付与はできたが、外すのは1枚選択の × のみだった。
群の整理で「このタグ、やっぱり外したい」が起きるので、**全選択カードに共通するタグ**だけ一括外しできるようにする。

出典: 2026-07-30 人間要望（T046 確認後）

## やること

- 複数選択インスペクタに、選択カード全員が持つ共通タグをチップ表示
- × で選択カードすべてからそのタグを外す（`detachTagFromCards`）
- 一部のカードだけのタグは表示しない（誤削除防止）
- 一括付与 UI（T032）はそのまま

## 受け入れ条件

- [x] 2枚以上選択時、共通タグがチップで見え、× で全員から外れる
- [x] 共通でないタグはチップに出ない
- [x] 1枚選択時の × 挙動は変わらない
- [x] JSON 往復で結果が残る
- [x] check / test / smoke が緑
- [x] 人間が「群からタグをまとめて外せる」と確認する

## このカードでやらない

- 一部のカードだけから外す（1枚選択へ）
- タグの改名・統合 UI の変更
