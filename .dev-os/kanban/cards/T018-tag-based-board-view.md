## 目的

ドッグフードで欲しかった「人物特定→時系列」のようなボードの見方切替（O5）を、
**タグ絞り込みではなく関係ベースの動的ビュー**で満たす。1枚のボードのまま、
選択した対象と関係する情報だけを浮かび上がらせる。既存の関連強調（T017/T023）の延長として
最小スコープで始める。

出典: T015 / O5（改訂13でタグ非依存へ再定義。旧「タグ別表示」は廃止）
前提: 糸の最小仕様は T028 で探索済み（2点間・無分類・後付けラベル・1:1維持）。
ビューの入力は糸・関係・考察であってタグではない（改訂13・§1）。

## 背景（再定義メモ）

- 旧設計: `tags` で表示対象を絞る「タグ別表示」。だが唯一のタグ実データ（デモ）は
  すべて意味分類で、§1「意味分類はタグにしない」と矛盾していた（改訂13で撤回）。
- O5の本質は「特定の人物・場所・出来事に関係する情報を抽出し、必要なら作中時間／前後関係で並べる」
  複合要求。タグ単独では満たせない。
- 現状の素地: 選択カードの関連を強調・区別（T017/T023 done）。これがビューの最初の芽。
- 初期スコープは絞る（資料§18）。時間軸（作中日時・前後関係）は別トラック（v2）で、本カードでは扱わない。

## 受け入れ条件

- [ ] 選択した対象（カード）を起点に、関係する情報だけを浮かび上がらせる／絞る導線がある（入力はタグではなく糸・関係）
- [ ] 「全部見る」に戻れる
- [ ] 絞り込み中も糸・配置・選択の基本操作は壊れない（非表示カードへの糸の扱いは実装時に一文で決めてPLANへ）
- [ ] 複数 Board エンティティや Era／タイムライン専用ビューは作らない（Won't維持）
- [ ] 意味分類タグを表示の正本にしない（改訂13・§1）
- [ ] 行数警告基準（15ファイル / 3,000行）を意識し、超過見込みなら評価パケットへの人間GOが作業ログにある
- [ ] 最新コミットで check / test / smoke が緑
- [ ] 人間が「ボードを分けなくても視点を切り替えられる」と確認する

## このカードでやらない

- タグによる絞り込み（改訂13で廃止）
- 複数ボード／Eraビュー／タイムライン専用ビュー
- 作中日時・前後関係・出来事化（v2別トラック）
- 本格インスペクタ全面（url編集など）
- カードサイズ可変（T022）
