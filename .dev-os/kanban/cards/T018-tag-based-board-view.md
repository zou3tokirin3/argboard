## 目的

ドッグフードで欲しかった「人物特定→時系列」のようなボードの見方切替（O5）を、
**タグ絞り込みではなく関係ベースの動的ビュー**で満たす。1枚のボードのまま、
選択した対象と関係する情報だけを浮かび上がらせる。既存の関連強調（T017/T023）の延長として
最小スコープで始める。

出典: T015 / O5（改訂13でタグ非依存へ再定義。旧「タグ別表示」は廃止）
前提: 糸の最小仕様は T028 で探索済み（2点間・無分類・後付けラベル・1:1維持）。
ビューの入力は糸・関係・考察であってタグではない（改訂13・§1）。

## 背景（再定義メモ）

- 旧設計: `tags` で表示対象を絞る「タグ別表示」。だが唯一のタグ実データ（デモ）は
  すべて意味分類で、§1「意味分類はタグにしない」と矛盾していた（改訂13で撤回）。
- O5の本質は「特定の人物・場所・出来事に関係する情報を抽出し、必要なら作中時間／前後関係で並べる」
  複合要求。タグ単独では満たせない。
- 現状の素地: 選択カードの関連を強調・区別（T017/T023 done）。これがビューの最初の芽。
- 初期スコープは絞る（資料§18）。時間軸（作中日時・前後関係）は別トラック（v2）で、本カードでは扱わない。

## 設計案（O5をどう満たすか・資料§16/§20）

O5＝「特定の人物・場所・出来事に関係する情報を抽出し、必要なら作中時間／前後関係で並べる」を2つに分解する。

### (a) フォーカスビュー ＝ 本カードで満たす「関係抽出」

- 起点カードを1枚選ぶ（例: 「田中」を表す発見／考察カード、「23:17の短波ラジオ」）。人物・場所・出来事は
  エンティティではなく**カードで表す**（名寄せ辞書は Won't §12）。
- その起点から**糸で到達できるカードだけを浮かび上がらせ、他を伏せる**。既定は1ホップ＝既存の関連強調が使う
  到達集合（`board.tsx` の `relatedIds`）をそのまま流用する。
- 到達集合には**考察カード（thought）も含む**（資料§16「発見＋考察」）。
- 「全部見る」で解除。ビューは **session 状態**で、`Board.positions` もカードも複製・変更しない
  （§16「元データを複製しない」）。糸は**両端が表示中のときだけ描画**（失効パケットの確定案を継承）。
- 入力は**糸（到達関係）と役割（finding/thought）**。タグ・意味分類は入力にしない（改訂13・§1）。
  将来 糸→考察の昇格（T028）が入れば「考察に使われた発見」も到達集合として自然に辿れる。

### (b) 作中時系列 ＝ 本カードでは満たさない（明示的に持ち越し）

- O5の「→時系列」は作中日時／前後関係という構造化データが要る（資料§13）。現状データモデルに無く、
  記録日時 `foundAt` で代用してはいけない（作中≠記録）。
- よって本カードは「関係する情報の抽出」までを満たし、「作中時間で並べる」は
  時間構造化トラック（出来事・作中日時・前後関係）へ渡す。

### §16の例との対応（何が満たされ、何が残るか）

| §16の例フィールド | 意味 | T018初期スコープ |
| --- | --- | --- |
| 対象人物：田中 | 起点＝関係対象 | ○ フォーカス起点カード |
| 対象：発見＋考察 | 到達集合の中身 | ○ thought も含む |
| 表示形式：タイムライン | 表示形式 | × 別トラック（v2） |
| 時間軸：作中日時 | 構造化時間 | × 未実装・別トラック |

→ O5の**抽出半分をT018が満たし、時系列半分は明示的に持ち越す**。「最初から全部構造化しない」（資料§22.3）と
「関係を入力にする・タグを入力にしない」（改訂13）を両立する。Nホップ展開・境界の続き表示は「できたら」。

## 考察カード＝再び開けるレンズ（3層の「記録」・2026-07-23 壁打ち）

- 焦点ビューの正体は「**起点カード ＋ ホップ深さ**」。起点が考察カードのとき、**考察カードそのものがそのビューの記録**になる。
- 考察カードは項目として永続保存され JSON 往復もされるため、「もう一度その視点で見たい」は
  **同じ考察カードを焦点に選び直すだけ**で再現できる。**保存する新規オブジェクトは無い**
  （§16「元データを複製しない」／Won't §12「ビューの版管理はやらない＝手動保存で代替」と一致）。
- 記録されないのは session 状態（何周目か・viewport）だけ。
- **帰結**: 昇格A（糸→考察）の価値は「打ち直し省略」ではなく**「再び開けるレンズの取っ手を鋳造すること」**。
  辺（糸ラベル）は焦点の起点になれず、点（考察カード）にして初めて呼び出せる → T028に反映済み。
- **2層⇔3層の往復**: 焦点は読む／編集は「全部見る」で行う（暫定判断④）。**蝶番は「全部見る」ボタン**。
  往復が煩わしいと観測されたら暫定判断④の見直しトリガ（沈んだカードに触れたい／起点乗り換え）が発火する。
- **足すとしたら**「**名前付きビューの棚**」（考察カードidを並べクリックで呼ぶ薄いUI・データ複製なし）だけ。
  暫定判断③のトリガ（よく戻る起点が3〜4個へ固まる）で昇格。今は作らない。

## 表示挙動の暫定判断（条件付き・使いながら調整する）

以下は壁打ちで **暫定採用** した表示挙動。**凍結しない**。いずれも実プレイでの観測で差し替える前提（§16の昇格作法）。
各判断には「見直しトリガ（＝これが観測されたら振り替える）」を付ける。**実装／ドッグフード時にこの節を必ず見直す**（受け入れ条件に固定）。

| # | 暫定判断 | 理由（要点） | 見直しトリガ → 振り替え先 |
| --- | --- | --- | --- |
| 1 | **圏外は沈める（消さない）** | 位置感覚と核体験③「眺めて楽しい」を壊さない。沈んだ影がNホップ展開の「手を伸ばす」対象になる | 盤面が増え（目安50枚超）沈んだ影がノイズと観測 → 「密度に応じて消す／沈めるを切替」へ |
| 2 | **段階展開（既定1ホップ・1ボタンで1周ずつ）** | 捜査グラフは小世界でN=3前後で全到達しフィルタが無効化。ホップ数スライダー（1〜5）は採らない | 「毎回すぐ2周目を押す」が定着 → 既定ホップ数の変更（"考察起点は自動2"の条件分岐は入れない＝規則を増やさない） |
| 3 | **トリガは1操作・分類は作らない** | 選択の既定挙動（起点=青／隣=濃青／他=そのまま）は変えない。選択即沈めは編集・糸張りと競合。カードに「ビュー」印を付けない＝昇格は結果であって操作ではない | 「よく戻る起点」が実際に3〜4個へ固まる → 「最近の起点」または名前付きビューを検討 |
| 4 | **沈んだカードは触れない** | 沈んだカードは見えるが反応しない。繋ぎ直しは「全部見る」で戻ってから | 「沈んだカードを起点に乗り換えたい」が観測 → 「クリックで起点乗り換え」を昇格（糸張りとの競合解消込みで別カード化） |

**振り替え口（埋め込み）**: 上記トリガが実プレイで観測されたら、その項目を本カードの**差し戻し履歴**へ1行で出すか、
O項目と同じ作法で**新規backlogカードへ昇格**する。この節は「決定」ではなく「観測待ちの暫定」であり、上書き可。

## 受け入れ条件

- [x] 選択した対象（カード）を起点に、関係する情報だけを浮かび上がらせる／絞る導線がある（入力はタグではなく糸・関係）
- [x] 「全部見る」に戻れる
- [x] 絞り込み中も糸・配置・選択の基本操作は壊れない（非表示カードへの糸の扱いは実装時に一文で決めてPLANへ）

- [x] 意味分類タグを表示の正本にしない（改訂13・§1）
- [x] 圏外は沈める（消さない）・段階展開（既定1ホップ）・トリガは1操作で選択挙動を変えない・沈んだカードは触れない、を暫定として満たす
- [x] 実装／ドッグフード時に「表示挙動の暫定判断」節の各見直しトリガを点検し、観測があれば差し戻し履歴か新規カードへ振り替える

- [ ] 人間が「ボードを分けなくても視点を切り替えられる」と確認する

## このカードでやらない

- タグによる絞り込み（改訂13で廃止）
- 複数ボード／Eraビュー／タイムライン専用ビュー
- 作中日時・前後関係・出来事化（v2別トラック）
- 本格インスペクタ全面（url編集など）
- カードサイズ可変（T022）
