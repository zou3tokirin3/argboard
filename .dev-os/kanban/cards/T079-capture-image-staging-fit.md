## 目的

探索でスクショを貼ったあとの新規入力（`ExploreImageStaging`）が、プレビュー固定長＋本文欄で
縦に伸びすぎて画面に収まらない。入力確定に必要なタイトル／操作が視界に入る高さに収める。

出典: 2026-10-10 人間フィードバック（T068 確認中。「新規入力画面、固定長で長すぎて画面に入らない」）

関連: [T068](T068-capture-existing-tag-suggest.md)（キャプチャ付帯・本カードへ分離） /
[T054](T054-explore-image-large-while-memo.md) / [T060](T060-adjustable-image-preview.md)

## 背景（起票時メモ）

- 現状プレビューは `max-height: min(52vh, 520px)`。加えてタイトル・本文（rows=5）・作中時間・URL・ボタンが縦積み
- ノートPC高さだとプレビューだけで半分以上を食い、タイトル／追加がスクロール先になる
- T060 は参照プレビュー（掘り中）のドラッグリサイズ。ステージング側の「初回貼り付けの確定 UI」は別問題
- 3秒キャプチャの主経路（画像なし1行）は触らない

### ready 確定（2026-10-10）

採択: **上限見直し**（折りたたみ UI は作らない）

- ステージング専用プレビュー: `max-height: min(28vh, 240px)`（掘り中参照 T060 の既定は触らない）
- 本文 `rows` を 5 → 3
- board の side-wide でステージングに 52vh/520 を戻す上書きをやめる
- 画像なしの通常キャプチャ行は変更しない

### 見込み flow

本体行 +0〜20（ほぼ CSS） / 操作 +0 / 概念 +0 / gzip +1KB未満 / Won't=No。
しきい値内 → 評価パケット不要。
