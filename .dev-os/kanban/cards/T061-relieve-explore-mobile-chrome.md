探索の核は「見つけた瞬間に1行で放り込む」。390px ではインストール案内・プロジェクト・
モード・JSON・キャプチャヒント・フィルタが積み上がり、ログの前にクロムが来る。

## 受け入れ条件

- [ ] 幅 390px 程度で、起動直後にキャプチャ入力がファーストビューに入る（インストール案内を閉じたあと）
- [ ] 粗いポインタ（タッチ）では `⌘V` などデスクトップ専用ヒントを出さない。ファイル選択など代替が残る
- [ ] ルートに `touch-action: manipulation` があり、ダブルタップズーム遅延が無い
- [ ] フルブリード箇所に `env(safe-area-inset-*)` があり、ノッチで切れない
- [ ] 既存のキャプチャ・フィルタ・JSON 書き出し／読み込みの機能は残る（場所は動かしてよい）
- [ ] flow しきい値（本体行 +200 / 操作 +3 / 概念 +2 / gzip +8KB / Won't）を意識し、超過見込みなら評価パケットへの人間GOが作業ログにある
