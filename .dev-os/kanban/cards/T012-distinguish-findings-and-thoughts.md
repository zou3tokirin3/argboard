## 目的

調査で見つけた事実・資料と、ユーザー自身の仮説・疑問・違和感を同じCardのまま区別する。
探索の3秒キャプチャは変えず、考察中に生まれた内容をボードへ直接置ける最小導線を作る。
T007、T006の完了後、T008のドッグフード前に行う。

## 受け入れ条件

- [ ] Cardへ任意の `role: "finding" | "thought"` を追加し、省略された既存カードはfindingとして扱う
- [ ] thoughtの `foundAt` は作成時刻として自動付与し、既存の発見順ソートを共用する
- [ ] 探索モードのキャプチャは常にfindingを作り、現在の1行＋Enter導線を遅くしない
- [ ] 考察モードに「考察カードを追加」の1行入力を置く
- [ ] Enterでthoughtを現在の表示領域中央へ配置・選択し、本文は既存インスペクタで編集できる
- [ ] 発見ログとボード上でthoughtを判別できるが、専用フィルタや新しい階層は作らない
- [ ] finding / thoughtは同じ配置・リンク・保存処理を使う
- [ ] 既存Project JSONをschema version 1のまま読み込める
- [ ] 15ファイル / 3,000行のv1絶対上限を守る。超える場合は機能を圧縮せずplannerへ差し戻す
- [ ] 最新コミットで check / test / smoke が緑
- [ ] 人間が「発見」と「自分の考察」を迷わず使い分けられるか確認する
