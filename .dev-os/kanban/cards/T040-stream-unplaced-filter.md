## 目的

配置作業中に「まだボードに乗っていないカードだけ」を発見ログで見られるようにする。
観測された摩擦（未配置だけ見たい）を、タグや複数選択と混ぜずに最小トグルで解く。

出典: [T038](T038-tag-visibility-and-stream-filters.md) 探索結論（案E・人間採択後に ready）。

## やること

- 発見ログの検索近くに **「未配置のみ」トグル**を置く
- ONのとき `boards[0].cardIds` に無いカードだけを一覧に出す
- 既存の検索（およびタグ起点フォーカス時の search 同期）と **AND**
- 状態は session のみ（JSONに載せない）
- ボード上のカードは消さない・沈めない（一覧側の作業ビュー）

## 受け入れ条件

- [ ] トグルONで未配置カードだけが発見ログに出る
- [ ] トグルOFFで従来どおり全件（検索条件は維持）
- [ ] 検索語と同時に使える（AND）
- [ ] タグ起点フォーカス（T033）と同時に壊れていない
- [ ] トグル状態がエクスポートJSONに載っていない
- [ ] 見込み flow が PLAN §4 しきい値内。超過なら評価パケットGOが作業ログにある
- [ ] 最新コミットで check / test / smoke が緑
- [ ] 人間が「配置作業が楽になった」と確認する（gate: human）

## このカードでやらない

- タグ単位の一覧絞り（T033が視点切替として担当。PLAN §1のタグ絞りビュー禁止を守る）
- 配置済みのみ・考察のみ（後回し）
- 複数選択・一括操作（**T032**）
- ボード側のフィルタ／カード非表示
- ボード上タグ表示（**T039**）
