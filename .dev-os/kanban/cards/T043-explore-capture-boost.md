## 目的

探索モードの連続追加を止めない。入力欄は1本のまま、直前入力の再利用と操作ヘルプで速度を上げる。
発見/考察の仕分けは入力時に分けず、あとから直せる別カード（T044）に任せる。

出典: 2026-07-28 人間要望／2026-07-29 縮小採択（入力欄2本＋フォーカスボタンは捨てる）

## やること

- 探索キャプチャは **1本のまま**（発見として追加。T012どおり）
- 連続入力補助: `↑`/`↓` で入力履歴を辿る（空欄または履歴閲覧中。編集中の新規行では↑を奪わない）
- 履歴は localStorage に残し、リロード後も消えない（最大50件・連続重複は畳む）
- ヘルプに操作を明記（`//`・URL・`↑`/`↓`・タグは後から）
- 既存の行内記法（`//` と URL抽出）と衝突しない

## 受け入れ条件

- [x] `↑`/`↓` で送信済み行を古い／新しい方向に辿れる
- [x] リロード後も履歴が残る（同一ブラウザ）
- [x] ヘルプに `↑`/`↓` と「タグはカード選択後」が書いてある
- [x] キーボード中心で連続追加でき、カーソル移動が増えない
- [x] 保存競合（T007）やモード遷移（T005/T021）が壊れない
- [x] 既存の行内記法（T026）とURL導線を壊さない
- [x] flow しきい値（本体行 +200 / 操作 +3 / 概念 +2 / gzip +8KB / Won't）を意識し、超過見込みなら評価パケットへの人間GOが作業ログにある
- [x] 最新コミットで check / test / smoke が緑
- [x] 人間が「探索で追加し続けやすい」と確認する

## このカードでやらない

- 発見/考察の入力欄分離・フォーカス専用ボタン
- 発見↔考察のあと仕訳（**T044**）
- 探索での画像貼付（**T045**）
- 検索/フィルタの大改修
- ボード編集機能の探索モード移植
