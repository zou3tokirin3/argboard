## 目的

探索モードが「入力1本だけ」に見えると存在意義が薄くなるため、
ガシガシ追加できる専用導線を足して、探索の速度と気持ちよさを上げる。

出典: 2026-07-28 人間要望（「画面が地味。もっと便利に追加機能が欲しい」）

## やること（候補を同梱して1カードで最小実装）

- 探索モードに追加専用のクイックアクション帯を置く（入力欄近傍）
- 最小でも次の2導線を入れる:
  - 「発見を追加」（既存キャプチャへフォーカス）
  - 「考察を追加」（考察1行入力へ直行、または即時追加）
- 連続入力を止めない補助（直前入力の再利用 or テンプレ挿入）を1つ入れる
- 既存の行内記法（`//` と URL抽出）と衝突しない

## 受け入れ条件

- [ ] 探索モードで、既存入力以外に「追加が速くなる」導線が少なくとも2つある
- [ ] キーボード中心でも操作でき、連続追加時にカーソル移動が少ない
- [ ] 追加導線を使っても保存競合（T007）やモード遷移（T005/T021）が壊れない
- [ ] 既存の行内記法（T026）とURL導線を壊さない
- [ ] flow しきい値（本体行 +200 / 操作 +3 / 概念 +2 / gzip +8KB / Won't）を意識し、超過見込みなら評価パケットへの人間GOが作業ログにある
- [ ] 最新コミットで check / test / smoke が緑
- [ ] 人間が「探索モードで追加し続ける意味がある」と確認する

## このカードでやらない

- 検索/フィルタ機能の大改修
- ボード編集機能の探索モード移植
- AI自動要約や自動分類の導入
