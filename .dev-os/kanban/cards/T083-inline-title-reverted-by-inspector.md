## 目的

**本番で起きているデータ消失バグ。**発見ログでタイトルをその場で直したあと（T053）、別のカードを選ぶと、
インスペクタが古いタイトルで書き戻し、直したタイトルが消える。

出典: 2026-10-20 T064 作り直し中の調査で発見。実ブラウザで再現確認済み

## 再現（2026-10-20・ヘッドレス Chrome）

1. 発見ログを広くする（wide）。カード A・B を作る
2. A を選び、発見ログのタイトル欄で `A-original` → `A-renamed` に直す
   → 保存される（`A-renamed`）
3. B を選ぶ
   → **A のタイトルが `A-original` に戻る**

## 原因

- インスペクタは A の下書き（title など）を自分で持ち、**カードが切り替わったときしか読み直さない**
- 選択が外れるとき、インスペクタは古い下書きの**全項目**を `updateCard` で書き戻す
- 発見ログのタイトル直しは別の道で保存しているので、インスペクタはそれを知らない
- 根本の整理は T082。本カードは止血

## 受け入れ条件

- [x] 上の再現手順で、B を選んだあとも A のタイトルが `A-renamed` のまま
- [x] インスペクタで編集した内容は従来どおり保存される（選択切り替え・debounce・blur）
- [x] 同じ型の上書きがメモ（body）・URL・作中時間でも起きない
- [x] flow しきい値を意識し、超過見込みなら評価パケットへの人間GOがある（止血・最小変更）
- [x] 最新コミットで check / test / smoke が緑
- [ ] 人間が「発見ログで直したタイトルが戻らない」と確認する

## 方針メモ（ready 時に確定）

- 最小の止血案: インスペクタが**自分で変えた項目だけ**を書き戻す（変えていない項目は送らない）。
  あわせて、変えていない項目はカードの最新値に追従させる
- `updateCard` の形を変えるかは T082 の論点なので、本カードではインスペクタ側で閉じる

## このカードでやらない

- 下書きの持ち方の作り直し（T082）
