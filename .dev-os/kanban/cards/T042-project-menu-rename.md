## 目的

プロジェクト切替・新規作成・名前変更は毎回触る操作ではないため、
常時表示を減らしつつ、必要時にすぐ開ける左上メニューへ寄せる。

出典: 2026-07-28 人間要望（「プロジェクト関連は左上の展開メニュー方式で出すだけでよい」）

## やること

- ヘッダ左上に「プロジェクト」展開メニュー（popover/dropdown）を置く
- 既存の「切替」「新規作成」をその中へ移す（機能は維持）
- 同メニューに「名前変更」を追加する（現在プロジェクトのみ）
- 名前変更は最小導線（入力1つ + 保存）に留める
- キーボード/タップで開閉でき、メニュー外クリックで閉じる

## 受け入れ条件

- [x] 左上の展開メニューからプロジェクト切替・新規作成・名前変更ができる
- [x] メニューを閉じた通常時はプロジェクト操作UIが主面を圧迫しない
- [x] 名前変更後、ヘッダ表示・保存済み一覧・再読み込み後の名称が一致する
- [x] 既存の active project 切替ロジック（`ACTIVE_PROJECT_KEY`）を壊さない
- [x] flow しきい値（本体行 +200 / 操作 +3 / 概念 +2 / gzip +8KB / Won't）を意識し、超過見込みなら評価パケットへの人間GOが作業ログにある
- [x] 最新コミットで check / test / smoke が緑
- [x] 人間が「普段は邪魔にならず、必要時に迷わず触れる」と確認する

## このカードでやらない

- プロジェクトの削除・アーカイブ・並び替え
- 複数プロジェクトの検索UI
- 権限/共有などクラウド管理機能
