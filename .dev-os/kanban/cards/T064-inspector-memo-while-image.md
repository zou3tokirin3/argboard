## 目的

発見ログ（左）でもインスペクタ（右）でも、添付スクショを**固定倍率で拡大**して読めるようにする。
右側から開いたときは、その拡大のまま**開いているカードのメモを編集**できる。

出典: 2026-08-26 人間要望（詳細でも見ながらメモ／左の拡大／倍率固定で左右まとめたい）
関連: T054（別カード追加）・T060（参照高さ）・T041（1枚）・T065（本カードに吸収） /
[T061](T061-relieve-explore-mobile-chrome.md)（探索の縦クロム・`touch-action` / safe-area は T061 前提。順序は T061 → 本カード）

## 採択したやり方（人間確認・2026-08-26）

**倍率固定拡大**（ピンチズームなし）:

- 画像クリック等でオーバーレイを開く
- 表示倍率は固定（第1候補: **自然ピクセル 1×**。ビューポートに収まりきらなければネイティブスクロール）
- 連続ズーム・パンジェスチャは作らない
- **左**（発見ログサムネ）と **右**（インスペクタのスクショ）は同じ拡大UIを使う
- 右から開いたとき（または拡大中いつでも）: 同じオーバーレイ内に**このカードのメモ**欄
- T054「大きく見ながら書く」（別カード追加）は消さない。入口を拡大と分ける

倍率の第2候補（実装前に1つに確定してよい）: ビューポート幅に合わせる contain 固定。1×で文字が小さすぎる端末向け。ready 時にどちらか書く。

## 背景（起票時メモ）

- インスペクタ: メモは編集可だが画像は compact（~180px）。「大きく見ながら書く」は別カード追加
- 発見ログ: サムネ 88×66。クリックは T054 参照開始。見る専用の拡大がない
- ピンチズームは T054/T060 で先送り。固定倍率＋スクロールなら概念が増えにくい

## 受け入れ条件（倍率ルール確定: 自然ピクセル 1×＋スクロール）

- [x] 発見ログの画像から、固定倍率の拡大表示を開ける
- [x] インスペクタの画像から、同じ拡大表示を開ける
- [x] 拡大中に、開いているカードのメモ（body）を編集できる（別カード追加ではない）
- [x] Esc または明示操作で拡大を閉じ、元の画面に戻れる
- [x] ピンチズーム・フリーパンは無い（はみ出しはスクロールで足りる）
- [x] T054 の別カード追加へ進む道が残っている、または入口が分かる
- [x] T041 の1枚制限・圧縮契約を壊さない
- [x] flow しきい値の見込みを作業ログに書く。超過見込みなら評価パケットへの人間GOがある
- [x] check / test / smoke が緑
- [x] 人間が「左でも右でも固定拡大で見られ、右経路ではメモも書ける」と確認する

## このカードでやらない

- ピンチズーム・ドラッグパンの本格実装
- 一覧サムネの常時大型化
- 1カード複数画像・OCR
- T054 の掘る／考察フローの置き換え
- ボードノードからの拡大（必要なら後続）
