## 目的

T031でタグを付けられるようになったが、**どこでタグが見えるか**が偏っている。
発見ログ（左）では `#tag` が出る一方、ボード上のカードにはタグが出ない。
整理の結果が盤面で読めないと、「付けたが見返せない」が別の形で戻る。

あわせて、整理・配置の作業中に「未配置だけ見たい」「（将来）タグや配置状態で選びたい」といった
**一覧側の絞り込み／選択の足場**が欲しい、という観測がある。本カードは実装前に見え方と
絞りの最小案を決める探索（実装は別カードに切り出してよい）。

出典: 2026-07-26 人間ドッグフード（T031確認後）。
「タグの見え方はどこかで考えて実装したい。今は左の一覧では見えるけどボードでは見えなかったりする。
あとは未配置だけとか、選択できたら良いかな」

## 背景（現物）

- 発見ログ: [`ui/stream.tsx`](../../../ui/stream.tsx) が `card.tags` を `#tag` 表示済み
- ボードノード: [`ui/board.tsx`](../../../ui/board.tsx) `BoardNode` は title / body プレビュー / url 印のみ。tags なし
- 検索: `filteredCards` は tags 文字列を対象にするが、専用の配置・タグ絞りUIはない
- ノード寸法: `NODE_WIDTH=235` / `NODE_HEIGHT=128` 固定。foreignObject 内容領域は高さ78（title2行＋body2行）
- 近接カード:
  - **T033** — 検索近くのタグボタン → フォーカスビュー（視点切替。見え方そのものではない）
  - **T032** — 矩形選択・一括タグ（選択の手段は近いが、一覧の絞りとは別）
  - **T019** — ボード上メモ先頭プレビュー（ノード情報密度の先例）

## 検討して決めること（ready 前）

1. **ボード上のタグ表示**
   - 常時小さな `#` 列か／選択中だけか／ホバーだけか
   - 種類が多いときの省略（+N）と、未定着の破線をボードでも出すか
   - ノード高さ・ノリ／糸の当たり（T014）を壊さないこと
2. **発見ログ（またはボード）の絞り**
   - 第一候補: **未配置のみ**（配置作業の摩擦が観測されている）
   - 拡張候補: タグ単位・配置済みのみ・考察のみ など（Won't／操作数を見て切る）
   - 「絞る」と「選ぶ（複数選択）」を混同しない。選択は T032 側と役割分担する
3. **T033 との境界**
   - ボードにタグを出す＝常時の可読性
   - T033＝一時的な視点切替
   - 両方いるか、片方が先か

## 決めたこと（探索結論・人間採択待ち）

### 1. ボード上タグ表示 → **常時・1行コンパクト（案A）**

| 案 | 内容 | 判定 |
|---|---|---|
| **A（採択）** | タグがあるカードは常時1行の `#tag` を出す | **採択** |
| B | 選択中だけ | 不採択（盤面スキャン時に「付けたが見返せない」が残る） |
| C | ホバーだけ | 不採択（タッチ／ざっと見る用途に弱い） |
| D | 出さない（T033だけ） | 不採択（視点切替は「今この筋」用。常時の所属ラベルではない） |

詳細:

- **位置**: `board-node__content` 内。title の下・body プレビューの上（または末尾1行）。`pointer-events: none` のまま（ドラッグ／糸ヒットを奪わない）
- **省略**: 1行に収まる分だけ `#name` を出し、残りは `+N`。ホバーで全文は出さない（ツールチップ任意でも可だが必須にしない）
- **未定着**: 使用1件は inspector と同じ破線（`is-unsettled`）をボードでも出す。整理の入口を盤面でも読めるようにする
- **寸法**: **`NODE_HEIGHT` は変えない**（T014の当たりを触らない）。タグがあるとき body プレビューを2行→1行に落として枠を捻出する（T019の密度先例を拡張）
- **操作**: ボード上の `#tag` はクリック不可。付与・削除はサイド（T031）、視点切替はサイドのタグボタン（T033）のまま
- **色・階層**: やらない（§1）

### 2. 発見ログの絞り → **「未配置のみ」トグルをやる（案E）。タグ絞り・考察のみは後回し**

| 候補 | 判定 | 理由 |
|---|---|---|
| **未配置のみ** | **やる（後続T040）** | 配置作業の摩擦が観測済み。`boards[0].cardIds` で判定できる。配置状態でありタグではない |
| タグ単位の一覧絞り | **やらない** | T033が「沈める視点」として担当済み。PLAN §1「タグ絞り込みビューは作らない」と衝突する |
| 配置済みのみ | **後回し** | 未配置トグルの裏返せば足りる見込み。痛みが出てから |
| 考察のみ | **後回し** | §14「痛みが出るまで作らない」。role 専用フィルタは今は観測不足 |
| 複数選択 | **本カード外** | T032（未採択）の役割。絞りと選ぶを混ぜない |

詳細:

- 入口: 発見ログの検索近くに **「未配置のみ」トグル**（session 限定。JSONに載せない）
- 合成: 既存の検索（＋タグ起点フォーカス時の search 同期）と **AND**。トグルONでも検索語は効く
- ボード側は絞らない（盤面からカードを消さない。一覧の作業ビューだけ）

### 3. T033 との境界

| | ボードタグ表示（T039） | T033 フォーカス |
|---|---|---|
| 目的 | 常時の可読性（何が付いているか） | 一時的な視点切替（今この筋で見る） |
| 効果 | ラベルを足す。カードは消えない | 圏外を沈める。消さない・触れない |
| 入口 | なし（常時） | サイドのタグボタン |
| 先後 | **表示を先**（痛みが直接・差分が小さい） | 既存done。絞り込みの代替として維持 |

両方いる。片方がもう片方を代替しない。

### PLAN §1 との読み（衝突しないこと）

- ボードに `#tag` を出す＝**整理属性の可視化**であり、意味分類の正本化ではない（正本は糸・考察・roleのまま）
- 「未配置のみ」＝**配置状態**の作業トグル。タグをワークフロー状態にする逃げ道ではない（案B制約3を壊さない）
- タグで一覧を消すビューは作らない（T033の沈める方式を侵食しない）
- 主要導線（キャプチャ・配置・糸・考察・フォーカス）はタグなしで完結したまま。表示は「付けた結果が読める」ためのもの
