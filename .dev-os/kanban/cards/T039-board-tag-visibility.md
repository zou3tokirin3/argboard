## 目的

整理で付けたタグがボード上でも読めるようにする。発見ログだけに `#tag` が出て盤面に出ない状態を解消し、
「付けたが見返せない」を防ぐ。

出典: [T038](T038-tag-visibility-and-stream-filters.md) 探索結論（案A・人間採択後に ready）。

## やること

- `BoardNode` の `board-node__content` にタグ1行を出す（タグがあるカードのみ）
- 1行に収まる分だけ `#name`、残りは `+N`
- 使用1件のタグは `is-unsettled`（破線）で区別（inspector と同趣旨）
- タグがあるとき body プレビューは2行→1行（`NODE_HEIGHT` / 糸・ノリ当たりは変えない）
- `pointer-events: none` を維持。ボード上タグはクリック不可（付与はT031、視点はT033）

## 受け入れ条件

- [ ] タグ付きカードのボードノードに `#tag` が常時見える
- [ ] タグが収まりきらないとき `+N` で省略される
- [ ] 使用1件のタグが未定着として区別できる
- [ ] タグなしカードのレイアウトが崩れない
- [ ] `NODE_HEIGHT`・糸ハンドル・ノリ領域の当たりが従来どおり（T014を壊さない）
- [ ] ボード上タグをクリックしても付与・視点切替が起きない
- [ ] 見込み flow が PLAN §4 しきい値内。超過なら評価パケットGOが作業ログにある
- [ ] 最新コミットで check / test / smoke が緑
- [ ] 人間が「盤面でタグが読める」と確認する（gate: human）

## このカードでやらない

- ノード高さの変更・カードサイズ可変（T022）
- タグの色・階層
- ボード上からのタグ付与／削除
- ボード上タグクリックでのフォーカス（T033の入口はサイドのまま）
- 発見ログの未配置絞り（**T040**）
