## 目的

モデルにある `tags` を実際に付けられるようにし、付けたタグを手がかりに可視化を切り替えられるようにする。
T018（タグ別表示）の入力側。どちらか一方だけ先にやる場合は、最小の付け方と最小の表示切替が揃うまでをセットとみなしてよい。

出典: T015 / O8

## 受け入れ条件

- [ ] カードにタグを付け／外せる最小導線がある（インスペクタまたは同等の軽いUI）
- [ ] 付けたタグが保存・エクスポート／インポートで失われない
- [ ] タグを手がかりにした可視化切替がある（T018と統合実装してよい。その場合は両カードの受け入れをまとめて満たす）
- [ ] 行数警告基準（15ファイル / 3,000行）を意識し、超過見込みなら評価パケットへの人間GOが作業ログにある
- [ ] 最新コミットで check / test / smoke が緑
- [ ] 人間が「タグを付けて見方を変えられる」と確認する

## このカードでやらない

- 本格インスペクタ（url編集・多機能プロパティパネル）
- タグの色・階層・オートコンプリート高度化（最小の文字列タグでよい）
