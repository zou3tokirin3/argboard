## 目的

画像を大きく出してメモするとき、プレビューが環境によって小さすぎて文字が読めない。
固定の `max-height` ではなく、**ユーザーが自分の画面で高さを変えられる**ようにする。

出典: 2026-08-19 人間要望（画像参照中のプレビューが小さすぎる。環境ごとに調整したい）
関連: T054（読める大きさで見ながら書く）・T045（初回貼付の大きめプレビュー）・
T041（1枚制限。本カードは表示だけ）

## 背景（起票時メモ）

- **探索**のプレビュー: `.capture-image-staging__preview img` が
  `max-height: min(52vh, 520px)`
- **思考モードのサイド**は上書きで `min(36vh, 280px)`（`ui/styles.css`）。
  幅 360px のパネル内なので、ここが「小さすぎる」の本命になりやすい
- 対象は画像参照（`ExploreImageReference`）。同じコンポーネントを探索／思考で使う
- T054 はピンチズーム・パン・ライトボックスをやらなかった。本カードも
  **高さの上限を変える**まで（画像内パンや拡大鏡は別）
- 記憶先の第一候補: **このブラウザの localStorage**（キャプチャ履歴と同じ）。
  画面の都合であり ARG の事実ではないので、プロジェクト JSON / `ui` には載せない
- 操作の候補（ready 時に1つに確定）:
  - **A**: プレビュー下辺をドラッグして高さを変える
  - **B**: スライダー（range）
  - **C**: 大きめ／標準の2段だけ（T022 のカードサイズに近い。環境差には弱い）
- 罠: キャプチャ1行＋大きい画像で、探索の縦や思考サイドの発見ログが潰れる
- 罠: 初回貼付（staging）まで同じノブにするか。本カードの主対象は「見ながら書く」参照中

## 受け入れ条件（ready 確定・2026-08-21・操作 A）

- [x] 画像参照中に、プレビュー下辺をドラッグして高さを変えられる
- [x] 変えた高さは、同じブラウザを開き直しても残る（プロジェクトには保存しない）
- [x] 探索と思考サイドは別々に覚える（片方の広い値がもう片方を潰さない）
- [x] 既定値は現状と同じ（探索 `min(52vh, 520px)` / 思考サイド `min(36vh, 280px)`）
- [x] キャプチャ入力（1行追加）はプレビューの下に残る
- [x] 初回貼付（staging）は触らない
- [x] ピンチズーム・画像内パン・ライトボックスは作らない
- [x] flow しきい値の見込みを作業ログに書く。超過見込みなら評価パケットへの人間GOがある
- [x] check / test / smoke が緑
- [ ] 人間が「自分の画面で文字が読める大きさにできる」と確認する

## このカードでやらない

- ボード上の画像ライトボックス・ピンチズーム（T054 のまま）
- 1カード複数画像、画像の実体サイズ・圧縮の変更（T041）
- プロジェクト単位・カード単位の表示サイズ永続化
- インスペクタ内の小さな画像欄のリサイズ
- T059（考察にも `foundVia`）との同時実装はしない（別カード）
- 初回貼付（staging）のリサイズ
