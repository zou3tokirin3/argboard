## 目的

糸の意味はラベルが本線で足りる可能性が高い。「関連 / 矛盾」の2種別は色分け以上の必然が薄く、特に「矛盾」の利用場面がユーザーに浮かびにくい。種別を残すか・改名・外すかを決め、PLAN と UI を揃える。

## 背景（起票時メモ）

- 現状: `kind: "connects" | "contradicts"`。矛盾は破線＋赤。
- ドッグフード感想: 矛盾の使い方が思いつかない。人物相関ではほぼ不要。
- 仮説: 矛盾は「繋いだ瞬間」ではなく「後から気づく判断」。最初から種別を選ばせるUIと合っていない。
- 候補:
  1. 現状維持（種別は関連/矛盾、意味はラベル）
  2. 種別名だけ変える（例: 衝突 / 対立仮説）
  3. 種別をやめてラベルだけにする
  4. 種別を増やし直す（要 PLAN 改訂）
- 推奨メモ（2026-07-12 壁打ち）: ラベル本線・種別は後回し（または矛盾を外す）
