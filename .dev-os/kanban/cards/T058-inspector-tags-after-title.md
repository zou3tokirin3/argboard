## 目的

考察モード右パネル（インスペクタ）で、タグ付け・整理 UI が下の方にあり
見落としやすい。タイトル（主張文・手がかり名）を書いた直後にタグを触れるよう、
**タグ欄をタイトルの次あたり**へ移す。

出典: 2026-08-13 人間要望（T057 実機確認後）
関連: T031（インスペクタの TagField）・T032（一括タグ）・T048（共通タグ一括外しは持たない）

## 背景（起票時メモ）

- **現状（単一カード選択）** `inspector.tsx` の並び:
  1. 見出し（発見/考察・role 切替・サイズ）
  2. タイトル
  3. 出典URL
  4. メモ
  5. 画像
  6. **TagField** ← ここ（下の方）
  7. つながり（糸一覧）
  8. 削除
- **複数選択時**は TagField が上（「N枚を整理」の直後）で、単一選択だけ順序が違う
- タグは「整理用途」（PLAN §1 / T031）。タイトルを確定した直後に付ける導線が自然
- 採用順: **タイトル → タグ → 出典URL → メモ → 画像 → つながり**
