## 目的

全部同じサイズだと長いメモや短い手がかりの可読性が揃わない。
必要ならカードごとにサイズを変えられるようにする。

出典: T015 / O6
優先度: できたら（T019のプレビューで足りるか先に見てからでよい）

## 受け入れ条件

- [ ] ボード上のカードについて、少なくとも2段階以上のサイズ（またはリサイズ）を選べる
- [ ] サイズはプロジェクト保存に残り、export/importで復元される
- [ ] 糸・ドラッグ移動・選択がサイズ変更後も破綻しない
- [ ] 行数警告基準（15ファイル / 3,000行）を意識し、超過見込みなら評価パケットへの人間GOが作業ログにある
- [ ] 最新コミットで check / test / smoke が緑
- [ ] 人間が「サイズを変えて読みやすくできる」と確認する

## このカードでやらない

- 自由変形の高度なレイアウトエンジン
- メモ先頭プレビュー自体（T019）
