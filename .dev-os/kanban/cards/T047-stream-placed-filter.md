## 目的

T040の「未配置のみ」と対になる絞り込みを足す。
配置済みカードだけを発見ログで見たい場面（ボード上の群の確認・再編集など）を、同じトグル帯で解く。

出典: 2026-07-29 人間要望（標準の絞り込みとして「未配置のみ」と対比して「配置済のみ」）／
T040「このカードでやらない」にあった後回し項目の回収。

## やること

- 発見ログのフィルタ帯に **「配置済のみ」** を追加（既存「未配置のみ」の隣）
- ONのとき `boards[0].cardIds` に含まれるカードだけを一覧に出す
- 「未配置のみ」と同時ONにしない（一方をONにしたら他方はOFF。排他）
- 既存の検索（およびタグ起点フォーカス時の search 同期）と **AND**
- 状態は session のみ（JSONに載せない）。既存 `unplacedOnly` と同系統でよい

## 受け入れ条件

- [x] 「配置済のみ」ONで配置済みカードだけが発見ログに出る
- [x] 「未配置のみ」ONで従来どおり未配置だけが出る
- [x] 両方同時にONにならない（排他）
- [x] どちらもOFFで従来どおり全件（検索条件は維持）
- [x] 検索語・タグ起点フォーカス（T033）と同時に壊れていない
- [x] トグル状態がエクスポートJSONに載っていない
- [x] flow しきい値を意識し、超過見込みなら評価パケットへの人間GOが作業ログにある
- [x] 最新コミットで check / test / smoke が緑
- [x] 人間が「未配置／配置済の対比で使いやすい」と確認する

## このカードでやらない

- 考察のみ・発見のみなどの別軸フィルタ
- ボード側のフィルタ／カード非表示
- フィルタ状態の永続化（プロジェクトJSON／localStorage）
