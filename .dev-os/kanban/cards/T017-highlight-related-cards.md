## 目的

ボード上でカードを選んだとき、糸で繋がるカードが一目で分かるようにする。
PLAN M4磨き「繋がったカードが光る」に近い核の磨き。

出典: T015 / O4

## 受け入れ条件

- [x] カード選択時、直接糸で繋がるカードが視覚的に強調される
- [x] 選択解除で強調が消える
- [x] 糸の選択・ラベル編集・要検討切替と干渉しない
- [x] 15ファイル / 3,000行のv1絶対上限を守る
- [x] 最新コミットで check / test / smoke が緑
- [x] 人間が「関係が一目で追える」と確認する

## このカードでやらない

- ホバーだけの強調に限定しない（選択中を本線とする。ホバー追加は行数に余裕があれば可）
- 2ホップ以上の関係の再帰強調
- タグ可視化（T018 / T020）
