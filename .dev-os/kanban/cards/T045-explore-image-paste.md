## 目的

探索中にスクショをまず残し、あとで分析・考察したい。いまは考察モードのインスペクタ貼付（T041）に寄っており、
探索の流れで貼れない／画像を見ながら事実や考察を書きにくい。

出典: 2026-07-29 人間要望（探索時の画像貼付、大きな画面を見ながらの作成）

## やること（候補を同梱して最小に切る）

- 探索モードでも画像ペーストできる導線（貼付先ルールを先に決める: 選択中カード／新規カード作成など）
- 貼った画像を十分大きく見ながら、title/body（または新規キャプチャ）を書ける表示
- T041の1枚制限・圧縮・zip媒体を再利用し、二重実装しない

## 受け入れ条件

- [x] 探索モードで画像を貼れる（ペースト第一級。ファイル選択は副次でよい）
- [x] 貼付先ルールがヘルプかUIで迷わず分かる
- [x] 画像を見ながら事実・考察テキストを追記できる（大きめ表示で足りるならT022連携で可）
- [x] T041の保存・圧縮・export/import契約を壊さない
- [x] flow しきい値を意識し、超過見込みなら評価パケットへの人間GOが作業ログにある
- [x] 最新コミットで check / test / smoke が緑
- [x] 人間が「探索で画像を残してから考えられる」と確認する

## このカードでやらない

- 1カード複数画像
- AIによる画像解析・自動OCR
- ボード編集の全面移植
