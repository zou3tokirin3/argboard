## 目的

T008ドッグフードで最大の摩擦だった「カード移動」を直す。
現状はピンの狭いヒットで動かし、糸のヒットと重なると掴めない。
付箋を指でずらすように、カード本体の広い範囲で移動できるようにする。

## 受け入れ条件

- [x] カード本体（紙面）のドラッグで移動できる。ピン専用操作に依存しない
- [x] 糸のヒット領域と重なっていても、カード本体を掴んで移動を開始できる
- [x] 糸を掴む操作（選択・ラベル編集）と、糸ハンドルから張る操作は維持する
- [x] パン（背景ドラッグ）とカード移動が取り違えられない
- [x] 既存smokeの糸張り・配置シナリオが緑のまま
- [x] 本体行数の絶対上限（15ファイル / 3,000行）を守る。超える場合は機能を圧縮せずplannerへ差し戻す
- [ ] 人間が「付箋をずらす感覚で移動できる」と確認する

## このカードでやらない

- 保存状態インジケータの改善（操作回避で凌げるため後回し）
- 複数ボード、タグ可視化、カードサイズ可変、メモ先頭プレビュー
- 選択中の関係カード強調（M4磨き候補として別扱い）
