## 目的

選択中カードのハイライトと、糸で繋がるカードの関係強調が似ていて、
「自分が選んでいるのか／関係として光っているのか」が判別しづらい。
探索モードでも関係強調が残るのは良いので、2状態の差をはっきりさせる。

出典: T017 ドッグフード観察（人間）

- [x] 選択解除で関係強調も消える（T017の挙動は維持）
- [x] 探索／考察どちらのモードでも、上記の区別が分かる
- [x] 糸の選択・ラベル編集・要検討切替と干渉しない
- [x] 行数警告基準（15ファイル / 3,000行）を意識し、超過見込みなら評価パケットへの人間GOが作業ログにある

## このカードでやらない

- 2ホップ以上の関係の再帰強調
- ホバー専用の別強調の新設（必要なら行数余裕時のみ）
- タグ可視化（T018 / T020）
