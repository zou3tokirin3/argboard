## 目的

選択中カードのハイライトと、糸で繋がるカードの関係強調が似ていて、
「自分が選んでいるのか／関係として光っているのか」が判別しづらい。
探索モードでも関係強調が残るのは良いので、2状態の差をはっきりさせる。

出典: T017 ドッグフード観察（人間）

## 受け入れ条件

- [ ] ボード上で「ユーザーが選択中のカード」と「選択に紐づく関係強調のカード」が、色・線・塗りなどの差で一目で区別できる
- [ ] 選択解除で関係強調も消える（T017の挙動は維持）
- [ ] 探索／考察どちらのモードでも、上記の区別が分かる
- [ ] 糸の選択・ラベル編集・要検討切替と干渉しない
- [ ] 行数警告基準（15ファイル / 3,000行）を意識し、超過見込みなら評価パケットへの人間GOが作業ログにある
- [ ] 最新コミットで check / test / smoke が緑
- [ ] 人間が「選んでいるカードと関係カードを取り違えない」と確認する

## このカードでやらない

- 2ホップ以上の関係の再帰強調
- ホバー専用の別強調の新設（必要なら行数余裕時のみ）
- タグ可視化（T018 / T020）
