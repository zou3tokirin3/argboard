## 目的

探索では速度優先で一律「発見」として残し、あとから「これは考察だった」と直せるようにする。
入力時点で発見/考察を分けさせない（T043縮小・T012との整合）。

出典: 2026-07-29 人間要望（「入力欄を分けなくてよい。あとで仕訳可能にするのはあり」）

## やること

- 選択中カードで `role` を `finding` ↔ `thought` に切り替えるUIを置く（インスペクタ想定）
- 切替は既存 `addCard` / 表示ラベル（発見ログ・ボード・インスペクタ）と矛盾しない
- 必要なら `card_updated` イベントに role 変更を残す（リプレイ整合は最小で）

## 受け入れ条件

- [x] 既存カードの発見↔考察をあとから切り替えられる
- [x] 切替後、発見ログ・ボード・インスペクタの表示が揃う
- [x] 探索キャプチャは引き続き finding のまま（入力時仕分けを増やさない）
- [x] 保存・リロード後も role が残る
- [x] flow しきい値を意識し、超過見込みなら評価パケットへの人間GOが作業ログにある
- [x] 最新コミットで check / test / smoke が緑
- [x] 人間が「あとから直せるので入力時に迷わない」と確認する

## このカードでやらない

- キャプチャ入力欄の二重化
- 考察ステータス（確度・棄却など。T029どおり当面持たない）
- 一括で role を変える（必要なら後続）
