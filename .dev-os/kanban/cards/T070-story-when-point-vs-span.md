## 目的

作中時間を持つ出来事を、**瞬間（点）**で残すか **期間（幅）**で残すか、
データ形と表示の前提を決める。実装を決め打ちせず、採択または見送り（点のみ継続）を残す。

出典: 2026-10-04 人間壁打ち（タイムラインは時間×人物レーン想定。カードは起点／終点で
見え方が違うので点と幅を検討してよい。T069 実装中にはスコープを混ぜない）

関連: T069（`storyWhen` 自由文1本・時あり/時なし絞り） / T018（O5の時系列半分の持ち越し） /
PLAN 改訂13（時間構造化トラック） / 後続候補の人物レーン・タイムライン合成ビュー /

## 背景（起票時メモ）

- T069 は意図的に **`storyWhen?: string` 1本**。タイトル埋め込みからの脱出と絞り分けが目的
- タイムラインを人物レーンで見るとき、出来事は次のような型に分かれうる:
  1. **瞬間** — 「23:17に短波」→ 点
  2. **期間** — 「夜勤で倉庫にいた」→ 帯（start–end）
  3. **片側だけ** — 開始のみ／終了のみ → キャップ付きの不完全帯
  4. **バケットだけ** — 「Day3」「夜」→ 精確座標ではなく小区画に置く
- 全部を期間必須にするとキャプチャが重くなる。点のまま残せる道が必要
- `foundAt` は壁時計のまま触らない。前後関係エッジはこのカードの必須結論ではない
- レーン軸は当面 **人物のみ**（場所レーンは後続）。本カードは主に **時間の点/幅モデル**

### 採択（2026-10-04 人間）

**任意の2欄**: 起点（位置）＋ 帯の後ろ（任意）。2欄目が空なら点。

| 欄 | フィールド | 意味 |
|---|---|---|
| 起点 | `storyWhen?: string`（既存） | 点の位置／帯の左端。自由文 |
| 帯の後ろ | `storyUntil?: string`（新規・T072） | 空＝点。入っていれば帯。終端時刻（`13:00`）または長さ（`20min` / `20分`） |

- 必須にしない。どちらか一方だけでも可（起点のみ＝点、帯のみ＝幅だけの帯／右端キャップ）
- 日時ピッカー・厳密型・自動パース必須化はしない（自由文のまま）
- 「時あり」＝ `storyWhen` か `storyUntil` のどちらかが入っている
- 既存カードは `storyUntil` なし＝これまでどおり点
- タイムライン表示前提（後続カードへ）:
  - 帯なし → 点
  - 帯あり・終端時刻 → 両端帯（片側だけならキャップ）
  - 帯あり・長さ → 起点からその長さの帯（起点なしは幅だけ・軸位置なし）
  - `夜` / `Day3` など読めない語 → 点ラベルのまま
- 人物レーンUI・タイムライン描画は本カード外（実装は T072＝データ／編集面まで）

見送りしなかった候補: 点のみ継続 / 単一フィールド＋記法パース / 表示型だけ先に決める
