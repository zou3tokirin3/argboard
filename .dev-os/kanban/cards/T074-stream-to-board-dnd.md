## 目的

考察モードで発見ログのカードをボードへ置くとき、タイトル／メタ付近を掴むと文字選択になり、
本体から掴んでもドロップが無視されることがある。核導線の摩擦なので直す。

出典: 2026-10-04 人間報告（タイトル掴み→文字選択、本体掴み→入らない）

## 背景（起票時メモ）

- ドラッグ可能条件は `isContemplate && !replaying`（`stream.tsx`）
- `draggable` は `stream-card__main` の `<button>` にだけ付いている。メタ行は対象外
- ボードは `application/x-argboard-card` が `types` に無いと `dragover` を拒否（黙って落ちる）
- テキスト子を掴むとブラウザの文字ドラッグが勝ち、MIME が載らないのが主因
- `<button draggable>` はブラウザ依存で弱い。ネストしたサムネ `<button>` もある

## 受け入れ条件

- [x] 考察モードで、カードのタイトル・本文・メタ行（時刻／状態ラベル）のいずれから掴んでもボードへドロップ配置できる
- [x] 掴み始めに文字選択ドラッグへ化けない（選択ハイライトが出て配置が失敗しない）
- [x] メタ行の操作ボタン（削除・掘る・role 等）・URL・サムネ操作は従来どおりクリックでき、そこからのドラッグはカード DnD を開始しない
- [x] 探索モードでは従来どおり DnD 不可（タイトル編集時の文字選択は維持）
- [x] 既存の配置済みカードを再度ドロップすると位置が更新される（現行 `placeCardOnBoard` と同じ）
- [x] flow しきい値の見込みを作業ログに書く（見込み: 本体 +40 前後 / 操作 +0 / 概念 +0 / gzip 微小 / Won't=No）
- [x] check / test が緑（smoke は本数上限のため足さず、人間確認で代替）
- [x] 人間が「タイトルやメタから掴んでもボードに入る」と確認する

## このカードでやらない

- ボード上カードの移動ヒット（糊帯）の変更
- DnD 以外の配置手段（ダブルクリック配置など）の新設
- カスタム MIME 以外へのフォールバック設計の大規模変更
