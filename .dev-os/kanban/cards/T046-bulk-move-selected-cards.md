## 目的

適当に置いたあとボードが狭くなったとき、矩形選択したカード群をまとめてずらしたい。
現状は複数選択（T032）があっても、ノリドラッグは常に1枚だけ動く。

出典: 2026-07-29 人間要望（「あとで狭くなったからカードまとめて移動したい」）

## やること

- 複数選択中に、選択に含まれるカードのノリを掴んだら **相対位置を保ったまま一括移動**
- 選択に含まれないカードのノリは従来どおり単一移動（必要なら選択をその1枚に）
- 既存の矩形選択・紙トグル（T032）と糊付け帯（T014）を壊さない
- 永続化は既存の配置イベント経路を再利用（1枚ずつでもまとめてでも、リプレイが破綻しない最小）

## 受け入れ条件

- [ ] 2枚以上選択した状態でノリドラッグすると、選択カードが相対位置を保って動く
- [ ] 選択外のカードは一緒に動かない
- [ ] 糸・パン・矩形選択・単一ドラッグが壊れない
- [ ] リロード後も最終位置が残る
- [ ] flow しきい値を意識し、超過見込みなら評価パケットへの人間GOが作業ログにある
- [ ] 最新コミットで check / test / smoke が緑
- [ ] 人間が「狭くなった群をまとめてずらせる」と確認する

## このカードでやらない

- 自動整列・グリッドスナップ
- 一括削除・一括role変更
- 探索モードへのボード編集移植
