## 目的

ボードとカード群が時間とともにどう育ったかをスライダー等で再生し、
振り返り（配信を含む）で捜査の流れを見せられるようにする。

出典: 2026-07-20 振り返り配信の需要観測
優先度: できたら（現行バックログの後。T024完了後が望ましい）

## 背景（起票時メモ）

- 段階1: `foundAt` / `createdAt` だけで「この時点までに存在したカードと糸」を粗く再生する。
  記録開始前の既存データにも遡れるが、位置は現在位置・削除物は出ない
- 段階2: T024のeventsがある期間は、配置・削除・要検討切替まで忠実に再生できる
- Won'tの「タイムラインビュー」との関係: これは出来事の時系列一覧ではなくボード状態の再生。
  着手時にPLANのWon't解釈を明確化し、必要なら§12へ注記する
- 配信向け演出（チャプター送り・削除物の幽霊表示・プレゼンモード）は本カードの範囲外

## 受け入れ条件

- [x] 考察モードで時間位置を選ぶと、その時点までに存在したカードと糸だけが表示される
- [x] events が無い／薄い期間は `foundAt` / `createdAt`（位置は現在）。events 期間は配置・削除・要検討切替を反映
- [x] 再生は連続時刻ではなく実行単位（イベント／発見・糸）のステップ。前後ステップと専用バーで操作できる
- [x] 再生位置は session のみ（JSONに書かない）。「いまに戻る」または探索モード切替で通常表示へ戻れる
- [x] 再生中は読み取り専用（配置・糸・削除・本文編集・考察追加が書き込まれない）
- [x] PLAN §12 に「タイムラインビュー（一覧）≠ ボード時点再生（T025）」の注記がある
- [x] 行数警告基準を意識し、評価パケットへの人間GOが作業ログにある
- [x] 最新コミットで check / test / smoke が緑
- [ ] 人間が「育ちを追えて楽しい」と確認する

## このカードでやらない

- 配信演出（チャプター・幽霊表示・プレゼンモード・再生アニメーション）
- 動画/GIF書き出し
- 履歴イベントの一覧UI（§12 タイムラインビュー）
