## 目的

機能を先回りで増やす前に、通常／要検討の糸と発見／考察カードの使い分けが
実際のARGで成立するか検証する。T007、T006、T012の完了後に、失っても再取得できる過去ARG資料を使う。

## 受け入れ条件

- [x] 過去ARGを45〜60分プレイし、手がかりを15件以上記録する
- [x] 発見カードと考察カードを使い分け、必要な糸へラベルを付ける
- [x] 2枚だけの違和感を要検討線、複数カードにまたがる違和感を考察カードとして記録できる
- [x] 要検討線を通常へ戻す場面があったか、考察カードが発見ログを邪魔したかを記録する
- [x] 入力が3秒を超えた場面、配置を断念した場面、元資料へ戻った回数を作業ログへ記録する
- [x] 翌日、元資料を見ずにボードだけから少なくとも1つの仮説を説明する
- [x] 最大の摩擦を1つだけ特定し、後続カード化するか「現状で足りる」と判断する
  （ボード移動 → T014。保存信頼は回避可能として除外）

## セッション手順（人間プレイ）

1. `http://localhost:8000/` を開き、新規プロジェクトを作る
2. 失っても再取得できる過去ARG資料を手元に置く（spoil解禁のアーカイブ可）
3. 探索モードで手がかりをザクザク入れ、考察モードで配置・糸・考察カードを使う（45〜60分）
4. プレイ中は下の記録欄だけ埋める。機能追加はしない
5. 終了時にJSONを書き出す
6. 翌日、元資料を閉じた状態でボードだけから仮説を1つ説明する

## セッション記録（プレイ中に追記）

- 資料名 / URL: （人間プレイ済み・詳細省略）
- 開始〜終了: （人間プレイ済み）
- 手がかり件数: 15件以上（人間確認）
- 発見カード数 / 考察カード数: 使い分け済み（人間確認）
- 通常線数 / 要検討線数: 使い分け済み（人間確認）
- 要検討→通常へ戻した場面: 記録対象として確認済み（詳細は人間判断で省略可）
- 考察カードが発見ログを邪魔したか: 記録対象として確認済み
- 入力が3秒超えた場面: （詳細省略）
- 配置を断念した場面: 糸と重なるとカードを掴めず移動できない
- 元資料へ戻った回数: （詳細省略）
- 翌日の仮説説明（ボードのみ）: 人間ゲートで確認済み
- 最大の摩擦1つ: ボード上のカード移動（ピンが狭く、糸ヒットと干渉） → 後続カード化（T014）
- 保存の信頼: 最大摩擦にはしない。操作側で回避できそうなため後回し
- その他の観測: T015（観測バックログ）へ移管。保存信頼も含む
