## 目的

機能を先回りで増やす前に、通常／要検討の糸と発見／考察カードの使い分けが
実際のARGで成立するか検証する。T007、T006、T012の完了後に、失っても再取得できる過去ARG資料を使う。

## 受け入れ条件

- [ ] 過去ARGを45〜60分プレイし、手がかりを15件以上記録する
- [ ] 発見カードと考察カードを使い分け、必要な糸へラベルを付ける
- [ ] 2枚だけの違和感を要検討線、複数カードにまたがる違和感を考察カードとして記録できる
- [ ] 要検討線を通常へ戻す場面があったか、考察カードが発見ログを邪魔したかを記録する
- [ ] 入力が3秒を超えた場面、配置を断念した場面、元資料へ戻った回数を作業ログへ記録する
- [ ] 翌日、元資料を見ずにボードだけから少なくとも1つの仮説を説明する
- [ ] 最大の摩擦を1つだけ特定し、後続カード化するか「現状で足りる」と判断する
