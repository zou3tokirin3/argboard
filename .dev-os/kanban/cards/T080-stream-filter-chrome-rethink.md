## 目的

発見ログ上部のフィルタ（配置・種別・成否・作中）が、同じチップ／アイコン語彙に寄っていて
「どれが何の仕事か」が伝わりにくい。もっとスマートに・アイコンの被りを減らして、
用途（view choice）が目で分かる帯にしたい。

## 背景（起票時メモ）

- T066 で配置／種別／成否のグループ分けとチップ化までは入った。その後に作中（時あり／時なし）が足され、帯がさらに denser になった
- 観測: アイコンが似て見え、ラベルを読まないと軸（配置 vs 種別 vs 成否 vs 作中）が取れない
- 「スマートに」は機能追加より **見え方・情報アーキテクチャの再検討** が先（フィルタ条件の AND ロジックをいじる必要は未確定）
- PLAN §8: フィルタは view choice。枠なし／セグメント寄り。調整（stepper）や行為と混ぜない
- T077 の ↑／↓ を view choice 族へ寄せる話と同系統の磨き。まとめて触るか、フィルタ帯だけ先かは ready で決める

### ready 確定（2026-10-11）

採択: **軸ごとに記号語彙を分け、グループ枠を外して view choice セグメントにする**（ロジック不変・フィルタ帯のみ）。

1. **枠**: 各軸の bordered box をやめ、帯全体は枠なし。軸の区切りは縦 hairline ＋短い軸ラベル
2. **配置**: ピン SVG をやめ **文字のみ**（未配／掲載）。空間の仕事は語で足り、円形アイコン帯から外す
3. **種別**: 発見○／考察破線□を維持（`CardRoleToggle` と同系）
4. **成否**: `ThoughtOutcomeIcon`（未検）を維持
5. **作中**: 時計円をやめ **横タイムライン**（時あり＝線上の点、時なし＝点のない破線）に置換
6. 短ラベル・AND・session・testid／aria は維持
7. **T077 ↑↓ は触らない**（後続）

### rework 確定（2026-10-11）

採択: **3択軸はボタン1つ＋クリックで循環**。数よりスマートさ優先。絞り意味（AND・session）は不変。

1. **配置**: すべて → 未配 → 掲載 → すべて（文字のみ・現在値をラベル表示）
2. **種別**: すべて → 発見 → 考察 → すべて（現在値の○／□を添える）
3. **作中**: すべて → 時あり → 時なし → すべて（現在値のタイムライン記号）
4. **成否**: すべて ↔ 未検（従来どおり1ボタン。off 時ラベルは「すべて」）
5. 軸ラベルは残す。testid は軸ごと1つに整理

### 見込み flow

本体行 +0〜60 / 操作 −3〜0（ボタン削減） / 概念 +0 / gzip +1KB未満 / Won't=No。
しきい値内 → 評価パケット不要。
