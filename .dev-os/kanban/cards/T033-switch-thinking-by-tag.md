## 目的

付けたタグを**検索窓で打ち直さずに1クリックで選べる**ようにし、「今はこの筋で考える」への
切り替えコストを下げる。タグを付ける動機の大半は再訪であり、選ぶ側が遅いなら付ける側も続かない。

出典: 2026-07-25 人間との設計相談（「検索するときにこのタグを速攻選択して、思考の切り替えを助ける手立てに
なることを期待してる」）。depends on T031（タグが存在しないと意味がない）。

## 先に解いておく緊張（重要・ready前に人間が読むこと）

**T018（2026-07-25 done）で「ビューの入力は糸・関係・考察であってタグではない」と明記し、
タグ絞り込みを廃した。**本カードはその領域に隣接するため、2つのレベルを区別して段階を分ける。

### レベル1（本カードのスコープ・原則に触れない）

- 検索窓の近くに**既出タグのチップを並べ、クリックで検索語として入る**だけ。
- `filteredCards`（[state.ts:172](../../../ui/state.ts)）が**既に tags を検索対象に含んでいる**ため、
  発見ログ（stream）はそのタグのカードだけになる。**実装はごく小さい**。
- これは「絞り込みビュー」ではなく**検索語の入力補助**。ボードの浮き沈みには一切触らない。
  T018のフォーカスビュー（糸ベース）と競合しない。
- ただし副作用に注意: 検索語なので**タグ名がタイトルや本文に含まれるカードも一緒に拾う**。
  完全一致でタグだけを選ぶかどうかは ready 時に確定する（planner案: タグチップは完全一致、
  手打ちの検索語は従来どおり部分一致）。

### レベル2（本カードではやらない・痛み観測待ち）

- **タグをフォーカスビューの起点にする**（ボードがタグで浮き沈みする）。
- これはT018の「タグ非依存」を明示的に緩めるため、**PLAN §1・§14の改訂と人間ゲートが必要**。
- レベル1を使ってなお「発見ログだけでは切り替わらない、ボードも切り替わってほしい」が
  観測されてから別カードで起票する。T018をdoneした翌日に原則を緩めない。

## やること（レベル1のみ）

- 既出タグのチップを検索の近くに出す。クリックで選択、再クリックで解除
- チップは使用件数の多い順（または最近使った順・ready時に確定）。上限12種（T031）なので溢れない
- キーボードだけで選べること
- 選択中であることが目で分かること（今どの筋で見ているかを見失わない）

## 受け入れ条件（起票時ドラフト・ready時に確定）

- [ ] 既出タグを1クリック（またはキーボード）で選び、発見ログがそのタグのカードに切り替わる
- [ ] 選択中のタグが表示され、解除もできる
- [ ] タグを持つカードが0件のときチップが出ない（空のデモで邪魔にならない）
- [ ] ボードの浮き沈み・T018フォーカスビューに一切影響していない（レベル2に踏み込んでいないことの実測）
- [ ] 手打ちの検索（従来の部分一致）が壊れていない
- [ ] 行数警告基準（15ファイル / 3,000行）を意識し、超過見込みなら評価パケットへの人間GOが作業ログにある
- [ ] 最新コミットで check / test / smoke が緑
- [ ] 人間が「思考の切り替えが速くなった」と確認する（gate: human）

## このカードでやらない

- **タグをフォーカスビューの起点にする**（レベル2・T018の原則緩和とPLAN改訂を伴う。痛み観測待ち）
- タグの AND/OR 複合条件・除外条件（まず単一選択で足りるか観測する）
- タグの色分け（§1・意味カテゴリ色はやらない）
- 発見ログの role 別専用フィルタ（§14「痛みが出るまで作らない」を維持）
