## 目的

[T073](T073-person-lane-timeline-view.md) の作中並び左パネルで、いま固定の時間順を
**昇順／降順で切り替え**できるようにする。機械的なソート切替でよい（新しいパースや
整合判定の強化はしない）。

出典: 2026-10-06 dogfood（独立左パネル着地後・使い勝手メモ）

関連: [T073](T073-person-lane-timeline-view.md) /
[T075](T075-multi-origin-story-timetable.md)（表の軸向きは別件）

## 背景（起票時メモ）

- T073 は弱パースキーで一方向に並べ、「順が怪しい」印まで出す
- 眺める向きを変えたいとき（終盤から遡る等）に、同じ集合の逆順が見たい
- 昇順＝いまの並び、降順＝その逆。バケツ語・逆行印の意味はキー順に追随すれば足りる
- session のみ。発見ログの並びや `foundAt` には触らない

### 本カードの想定スライス（ready で確定）

1. **対象**＝作中並びパネルのリストのみ
2. **操作**＝昇順／降順の切替（トグルまたは2ボタン）。入口はパネル見出し付近
3. **意味**＝既存 `sortLaneCards` の結果を正／逆にする機械的切替
4. **永続**＝session（再読込で消えてよい）。`Project.ui` は増やさない
5. **外す**＝カスタム並び替え・ドラッグ並べ替え・新しい時間パース

## 受け入れ条件（起票時ドラフト・ready時に確定）

- [ ] 作中並びパネルで昇順／降順を切り替えられる
- [ ] 切替後も同じ集合（起点・hops）で、キー順が反転して読める
- [ ] 「順が怪しい」印が、表示中の隣接順に追随する（または方針が作業ログにある）
- [ ] 発見ログ・ボード配置・T025 再生を壊さない
- [ ] 再読込でソート向きは消えてよい（session）
- [ ] flow しきい値を意識し、超過見込みなら評価パケットへの人間GOが作業ログにある
- [ ] 最新コミットで check / test / smoke が緑
- [ ] 人間が「昇順と降順を切り替えて追える」と確認する

## 確認観点（gate: human のとき）

表示: タブ・左上が **`ARGBoard · <release>+<id>`**（review 中）または **`ARGBoard · <release>`**（done 後）であること。
`<release>` は `ui/release.ts` の `APP_RELEASE`。review 中は `APP_PREVIEW` に本カード id を入れる。

- [ ] 作中で並べる → 昇順で時間を追える
- [ ] 降順に切り替えて逆向きに追える
- [ ] hops を変えても切替が効く
- [ ] 閉じて開き直したときの初期向きが自然（既定＝昇順でよい）
