## 背景（起票時メモ）

- T018 は関係抽出（フォーカス）まで。作中時系列は明示持ち越しだった
- T069〜T072 で作中時間の記録面は揃った（点／帯・キャプチャ・時あり絞り）
- 方針: **持つ場所**＝カード＋糸／**見える場所**＝合成ビュー／**持たない**＝別DB・Era・ボード座標＝時間
- 人物は型でも特殊タグでもなく、**起点に選んだ任意カード**（Entity 辞書なし）

### ready 確定（2026-10-04）

1. **見え方**＝単一起点の時間順リスト。点／帯は T072 の短い表示ラベル（`12:34` / `12:34–20min`）。軸キャンバスは作らない
2. **入口**＝トップモード切替の第三タブ（仮称「レーン」）。`Project.ui.mode` は `"explore" | "contemplate"` のまま。レーン表示は **session のみ**（再読込で消える）
3. **起点**＝任意カード1枚。選んだカード＝そのレーンの人物扱い（タグ必須なし）
4. **レーン集合**＝起点から **1ホップの糸先** ＋ **考察経由の2ホップ** のうち、`storyWhen` または `storyUntil` があるカード。時間なしは載せない
5. **並び**＝読める範囲で作中時間順。読めない語（`夜` / `Day3`）は落とさず、末尾寄りまたは「ラベルのみ」グループ
6. **名称**＝UIは「レーン」／「作中レーン」。T025「タイムライン」（ボード時点再生）とは別名
7. **Won't**＝§12「タイムラインビュー」を本カード＝最小リスト合成に限り部分解除（[packets/T073.md](../packets/T073.md) GO）
8. **後続**＝複数起点タイムテーブル＋点／帯は [T075](T075-multi-origin-story-timetable.md)

閉じた論点（旧 ready 前リスト）:

- 入口 → 専用第三タブ（session）
- レーン範囲 → 1ホップ＋考察経由2ホップ・時ありのみ
- Phase 1 → 時間順リスト（キャンバスは T075）
- §12 → リストに限り部分解除・パケット GO
- T025 名称 → 「レーン」で衝突回避

## 確認観点（gate: human のとき）

表示: タブ・左上が **`ARGBoard · <release>+<id>`**（review 中）または **`ARGBoard · <release>`**（done 後）であること。
`<release>` は `ui/release.ts` の `APP_RELEASE`。review 中は `APP_PREVIEW` に本カード id を入れる。

- [ ] 「レーン」タブ → 起点を選ぶ → 時ありカードが時間順に並ぶ
- [ ] 点と帯がラベルで区別できる
- [ ] レーンを離れてもボード配置が変わっていない。再読込でレーン状態が消える
- [ ] T025 のボード時点再生と取り違えない
