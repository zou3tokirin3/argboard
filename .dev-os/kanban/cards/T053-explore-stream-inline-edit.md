## 目的

探索で Enter 追加したあと「間違えた」と気づいても、今は **考察モードに切り替えて
カードを探し、Inspector で直す** しかない。探索のリズム（ザクザク）のまま
タイトル（必要なら本文）を訂正できるようにする。

T026 の仮タイトル・T045 の画像追記 UI と同系統の「後から直す」だが、
**テキストで追加した通常カード**向け。

出典: 2026-08-03 人間要望（思考モード切替が面倒だから探索中に直したい）

## 背景（起票時メモ）

- T005 で編集は考察モード + Inspector に置いた。探索はキャプチャ + 発見ログのみ
- 画像カードは T045 `ExploreCompose`（キャプチャ直上）で title/body/url を blur 保存済み
- `updateCard` / `card_updated` イベントは既存。Card スキーマ変更は不要
- 罠: キャプチャ Enter の連打リズムを奪わない（編集は **選択後** が安全）
- 罠: ストリーム上の `<strong>` クリックとカード選択・削除・畳みトグルの競合
- 最小スコープ案: 選択中カードのタイトルをインライン input 化、blur/Enter で保存
- 拡張案: 本文1行プレビュー横の編集、または軽い compose 行（T045 パターン流用）

## 受け入れ条件（起票時ドラフト・ready時に確定）

- [ ] 探索モードで、発見ログのカード **タイトル** をその場で編集できる
- [ ] 保存は既存 `updateCard` 経由（`card_updated` が追記される）
- [ ] キャプチャ欄の Enter 連打・新規追加のリズムが変わらない
- [ ] 再生中は編集不可（既存 read-only と同様）
- [ ] 考察モードの Inspector 編集と矛盾しない（同じカードを両方で壊さない）
- [ ] ツリー表示（T051）・検索・未配置/配置済フィルタと併用しても動く
- [ ] flow しきい値の見込みを作業ログに書く。超過見込みならパケットへの人間GOがある
- [ ] check / test / smoke が緑
- [ ] 人間が「打ち間違えた直後に探索のまま直せる」と確認する
