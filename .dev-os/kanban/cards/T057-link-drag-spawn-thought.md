## 目的

考察モードで、既存カードから糸を引いて**別カード上ではなく空のキャンバス**にドロップしたとき、
ドロップ位置に考察カード（思考ノート）を生成し、元カードとの糸を自動で張る。
「発見同士をつないで違和感が出た → その場で考察を立てる」導線を、
考察入力欄を離れずにボード上の操作だけで完結させる。

出典: 2026-08-13 人間要望
関連: T028（糸→考察の昇格A＝**既存糸**を考察化。本カードは**新規カード生成**で別操作）・
T029（考察カード最小仕様）・T012（role:thought）・T037（board drag 状態機械）

## 背景（起票時メモ）

- **現状**: 糸ハンドルからドラッグして別カード上で離すと `connectCards` のみ。
  空に離すと何も起きない（`board.tsx` `onPointerUp` で `dropId` が無い場合は no-op）。
- **考察の直接追加**: ツールバーの1行入力 → 画面中央配置・糸なし（`submitThought`）。
- **T028 昇格Aとの違い**: 昇格Aは「張った**後**の糸を考察に昇格」。本カードは「張りながら考察を**生む**」。
  データ型追加はどちらも不要（`addCard(role:thought)` ＋ `connectCards` の合成）。
- **糸の向き**: ドラッグ元（`fromId`）→ 新規考察カード（`toId`）の1:1通常糸（T028の1:1維持）。
- **タイトル**: `addCard` は空タイトル不可。プレースホルダー見出しで生成し、生成直後に選択＋
  インスペクタでタイトル編集にフォーカスする案を第一候補（ready時に確定）。

## 受け入れ条件（ready 確定・2026-08-13）

- [ ] 考察モードで、カードの糸ハンドルからドラッグし、**空キャンバス**で離すと、
  離した位置付近に `role:"thought"` の考察カードが1枚生成される（見出しはプレースホルダー「考察」）
- [ ] 生成と同時に、ドラッグ元カード → 新規考察カードへ通常糸（`connects`）が1本張られる
- [ ] 新規考察カードが選択され、インスペクタのタイトルがフォーカス＋全選択され、すぐ上書きできる
- [ ] 既存どおり、別カード上で離した場合は従来の `connectCards` のみ（本機能と競合しない）
- [ ] 元カード上で離した場合はキャンセル（生成しない）。クリック誤爆を空ドロップとみなさない
- [ ] 再生中（`isReplaying`）では生成しない（既存の link ドラッグ制約と同じ）
- [ ] 自己糸・重複糸の禁止など `applyConnectCards` の既存制約を守る
- [ ] flow しきい値（本体行 +200 / 操作 +3 / 概念 +2 / gzip +8KB / Won't）を意識し、
  超過見込みなら評価パケットへの人間GOが作業ログにある
- [ ] 最新コミットで check / test / smoke が緑
- [ ] 人間が「糸を引っ張るだけで考察が立てられ、元カードとつながっている」と確認する
