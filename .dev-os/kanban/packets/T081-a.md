### バンドラ／dev サーバー

**採択: esbuild**

試作確認（2026-10-21）:

```
node -e "require('esbuild').build({entryPoints:['ui/main.tsx'], bundle:true, ...})"
```

| 指標 | deno bundle（現行） | esbuild（試作） |
|---|---|---|
| 出力サイズ | 298.7 KB | 300.8 KB |
| gzip サイズ | **63,436 B** | **64,702 B** (+1,266 B) |
| ビルド時間 | 約 3 秒 | **13 ms** |

- `.ts` 拡張子つき import（`./foo.ts`）を `--bundle` で解決済み。追加設定不要。
- JSX: `--jsx=automatic --jsx-import-source=preact` で動作確認済み。
- gzip 差は +1.3 KB。予算ゲート（+8 KB 以内）に余裕で収まる。
- Vite は dev サーバー体験が良いが依存が多い。今の開発スタイル（build→serve）に dev サーバーは不要。esbuild 単体が最小。

### unit テストランナー

**採択: `node:test`（Node 組み込み）**

追加依存: **ゼロ**。

移行コスト:
- `Deno.test("名前", fn)` → `import { test } from "node:test"; test("名前", fn);`
- assert は全ファイルが `throw new Error(...)` のみ使用 → そのまま。
- テスト 20 本、機械的な一括置換で済む。

### fmt / lint

**採択: Biome**

- fmt + lint を 1 ツールで担当。
- `deno fmt` の整形スタイルに近い。
- Prettier + ESLint は 2 ツール＋設定ファイルが増える。Biome が軽い。

---

### 型チェック

**採択: `tsc --noEmit`**

`tsconfig.json` に以下を追加する必要あり:

```json
{
  "compilerOptions": {
    "allowImportingTsExtensions": true,
    "noEmit": true
  }
}
```

`ui/` は `.ts` / `.tsx` 拡張子つき import を使っているため必須。
`allowImportingTsExtensions` は `noEmit` または `emitDeclarationOnly` が前提。esbuild が出力するため問題なし。

## 4. `tools/budget.ts` の Deno API 移行難所

| Deno API | Node の代替 | 難易度 |
|---|---|---|
| `Deno.Command` | `node:child_process` の `spawn` / `execSync` | ★☆☆ |
| `Deno.cwd()` | `process.cwd()` | ★☆☆ |
| `Deno.makeTempDir` | `node:fs` `mkdtempSync` + `node:os` `tmpdir()` | ★☆☆ |
| `Deno.remove(path, {recursive})` | `node:fs` `rm(path, {recursive:true})` | ★☆☆ |
| `Deno.readTextFile` | `node:fs/promises` `readFile` (utf-8) | ★☆☆ |
| `Deno.readDir` | `node:fs/promises` `readdir({withFileTypes:true})` | ★☆☆ |
| `Deno.errors.NotFound` | `error.code === 'ENOENT'` | ★☆☆ |
| `Deno.args` | `process.argv.slice(2)` | ★☆☆ |
| `import.meta.main` | `process.argv[1] === fileURLToPath(import.meta.url)` | ★☆☆ |
| `deno task build`（内部呼び出し） | 新しいビルドコマンドに差し替え（B6 で対応） | ★★☆ |

全項目 1:1 で置き換え可能。Node 組み込みのみで外部依存なし。  
最も注意が必要なのは `buildGzipBytes` 内の `deno task build` 呼び出し（B1 完了後に差し替える）。
